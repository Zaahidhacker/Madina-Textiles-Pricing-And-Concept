# Madina Textiles — Social Media Management Proposal

A single-page proposal site prepared for **Shazan Hafeez, Madina Textiles**.

**Scope:** Facebook, TikTok, Instagram (new page setup) + existing WhatsApp community (daily stock & price updates).
**Deliverables:** 12 reels/month (Mon · Wed · Fri, 40–120s, edited in CapCut) + 8 weekend photo posts.
**Workflow:** Fazal records → CapCut edit + captions → Faizan uploads.
**Pricing:** LKR 40,000–60,000/month retainer (LKR 10,000–15,000/week). Itemized breakdown on request.

Includes a live market comparison against three Sri Lankan agencies (E Lanka Solution, Cypher Digital, HypeX) and a confetti "Accept Proposal" button.

## Run locally

```bash
python3 -m http.server 4173
# open http://localhost:4173
```

Or just open `index.html` directly — no build step, no dependencies.
